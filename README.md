Una experiencia inmersiva donde la literatura cobra vida a través de la voz, la noche y los susurros de los libros olvidados.

## ✨ Características
- Episodios con duración, descripción, libros mencionados y arte único
- Modo oscuro total (porque la literatura nocturna merece oscuridad)
- Likes y contador de reproducciones
- Búsqueda por título, autor, libro o etiquetas
- Responsive → se ve perfecto en móvil, tablet y desktop
- Subida de episodios privada (solo admin via Postman)

## 🛠️ Stack
| Parte      | Tecnología                    |
|------------|-------------------------------|
| Frontend   | React + Vite + TailwindCSS    |
| Backend    | Node.js + Express             |
| Database   | MongoDB Atlas                 |
| Hosting    | Vercel (frontend) + Render (backend) |
| Auth       | JWT                           |
| Deploy     | GitHub + Vercel + Render      |
